## The Project
This portfolio is an engineering project that demonstrates my approach to building modern, fast and accessible interfaces.

## Visual Design
Updated with a dark theme using:
- **Glassmorphism:** Adding visual depth to interfaces.
- **Dynamic gradients:** Supporting the personal brand.
- **Entrance animations:** Creating a fluid browsing experience.

## Architecture
Built with Astro v7, keeping the site static and lightweight while adding interactivity where needed.
