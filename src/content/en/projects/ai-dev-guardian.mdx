## The Project
An experimental but functional tool designed to act as a code guardian throughout development, using language models to identify insecure patterns.

## Technical Solution
The system locally analyses the code structure and key files to identify potential security risks, outdated dependencies and architectural issues.

## AI Capabilities
- LLM-assisted local vulnerability scanning.
- Security reports written in natural language.
- Refactoring suggestions to mitigate identified risks.

## Impact
Provides developers with an additional automated review layer before formal security audits.
