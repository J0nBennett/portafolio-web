## The Project
A tool for running enthusiasts who want to centralise training plans and track their progress visually.

## Features
- Weekly progress dashboard.
- Route and distance-goal management.
- A reactive interface built with React.

## Learning
This project helped me explore complex state architecture in React and use Vite for a fast development workflow.
