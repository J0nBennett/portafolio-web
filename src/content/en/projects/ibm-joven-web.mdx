## The Project
A comprehensive redesign of the IBM youth community platform. The goal was to centralise event information and resources in a visually engaging site that is easy to maintain.

## Technical Solution
I implemented a workflow that allows coordinators to update events in Google Sheets, synchronising the data at build time or through an API for real-time display.

## Challenges
- **Performance:** Optimising high-resolution gallery images without slowing page loads.
- **UX:** Designing intuitive navigation for both desktop and mobile.

## Outcome
A platform that improves internal communication and the visibility of youth activities.
